RIS-Assisted Physical Layer Key Generation for Secure Wireless Communications

张三, 王五*, 李四

发表于: IEEE Transactions on Wireless Communications, 2026

📄 PDF (Preprint)
🔗 DOI 链接
💻 GitHub 代码
 
 

📌 Abstract (摘要)

针对静态无线环境中信道随机性不足导致物理层密钥生成率低的问题，本文提出了一种基于智能反射面（RIS）辅助的密钥生成机制。通过联合优化基站的波束成形矩阵和RIS的相移矩阵，我们主动构造了快速时变且高熵的等效级联信道。仿真结果表明，与传统方案相比，该方案将密钥生成率提升了 120%。

💡 Key Contributions (核心贡献)

  • 建立了一种新颖的交替优化算法，解决 RIS 相移与密钥生成率最大化的非凸优化问题。
  • 在相关信道模型下，推导了具有被动窃听者场景下的安全密钥容量闭式下界。
  • 开源了基于 MATLAB 的完整相移优化与信道探测代码，便于后续研究复现。
